# Botón 4 al abrir inventario (Fabric 1.21.11)

Al abrir el inventario de Minecraft se presiona automáticamente el botón 4 del mouse.

## Cómo conseguir el .jar con GitHub
1. Creá un repositorio nuevo en GitHub y subí todo el contenido de esta carpeta.
2. Entrá a la pestaña **Actions** y esperá que termine el workflow "Compilar mod".
3. Abrí esa ejecución y bajá el artefacto **boton4-mod** (un zip con el .jar).
4. Copiá el .jar (el que NO termina en `-sources`) a la carpeta `mods` de Minecraft.

## Requisitos
- Minecraft 1.21.11 con Fabric Loader 0.18.1 o superior
- Fabric API
